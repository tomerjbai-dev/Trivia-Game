# תוכנית Milestone 1 – בסיס אפליקציה וניווט עובד

מקורות: `MILESTONES.md` (Milestone 1), `PRD.md`, `ARCHITECTURE.md`, `DESIGN.md` והתמונות ב-`spec/`.
מצב נוכחי: אין עדיין קוד בפרויקט — רק `spec/`, `CLAUDE.md` ו-`.gitignore`. ה-Repository מחובר ל-`tomerjbai-dev/Trivia-Game`. Node 24 / npm 11 מותקנים.

## 1. היקף

**כלול:**
- הקמת פרויקט Next.js (App Router) + React + TypeScript + CSS Modules בתיקייה הקיימת.
- App Shell: `lang="he" dir="rtl"`, כותרת "חכמולוגים" בראש כל מסך, סרגל ניווט תחתון קבוע עם שלושה יעדים וסימון היעד הפעיל.
- שלושה מסכים: בית, טריוויה (תיבת נושא + כפתור "שאלה חדשה" לא מחובר), אודות.
- בסיס עיצובי: Heebo, משתני צבע (כולל המשלימים), טיפוגרפיה, כפתורים, שדה קלט, כרטיסים, צל, פינות, Spacing ופריסה Mobile-first עם רוחב תוכן מקסימלי 480px.
- כלי איכות: typecheck, lint, build, ובדיקות בסיסיות ב-Vitest.

**לא כלול (Milestones הבאים):** קריאה ל-AI / `POST /api/questions`, `.env.example` ומפתחות, מצבי טעינה/שאלה/משוב/שגיאה, Moderation, Manifest/PWA ואייקוני אפליקציה, Playwright, ליטוש עיצוב מלא מול ה-Mockups.

**במפורש לא לממש (סותר את ה-PRD):** אייקון הגדרות, יעד "תוצאות", כפתור "בדיקת תשובה", אזור "הסבר", שדה נושא במסך הבית.

## 2. הקמת הפרויקט

- **הקמה ידנית ולא דרך `create-next-app`:** הכלי מסרב לעבוד בתיקייה שכבר מכילה קבצים (`spec/`, `CLAUDE.md`) ועלול לגעת ב-`.gitignore`. לכן כותבים `package.json` ידנית ומתקינים חבילות ב-`npm install`.
- **תלויות:** `next`, `react`, `react-dom` (גרסאות יציבות עדכניות).
- **תלויות פיתוח:** `typescript`, `@types/node`, `@types/react`, `@types/react-dom`, `eslint`, `eslint-config-next`, `vitest`, `@vitejs/plugin-react`, `jsdom`, `@testing-library/react`, `@testing-library/jest-dom`, `@testing-library/user-event`.
- `package-lock.json` נשמר (נעילת גרסאות, לפי ARCHITECTURE 2.8).
- **Scripts ב-`package.json`:**
  - `dev` → `next dev`
  - `build` → `next build`
  - `start` → `next start`
  - `typecheck` → `tsc --noEmit`
  - `lint` → `eslint .`
  - `test` → `vitest run`
- `.gitignore` הקיים כבר מכסה `node_modules/`, `.next/`, `.env*`, `*.tsbuildinfo`, `coverage/` — אין צורך לשנות. אם יתגלה קובץ נוסף שנוצר (למשל `next-env.d.ts` — **כן נכלל ב-Git** לפי ברירת המחדל של Next), לא מוסיפים אותו.
- אין `.env.example` ואין `.env.local` ב-Milestone זה (אין משתני סביבה עדיין; נוספים ב-Milestone 2).

## 4. מבנה וגישה

### 4.1 ניתוב (Routing)
- כל מסך הוא כתובת נפרדת ב-App Router: `/` (בית), `/trivia` (טריוויה), `/about` (אודות). מעבר בין מסכים דרך `next/link` — ללא טעינה מחדש של הדף, ולכן מצב ה-Context נשמר.
- אין דפים נוספים. כתובת לא קיימת → דף 404 ברירת המחדל של Next (לא נדרש עיצוב).
- יתועד כ-ADR-1 ב-ARCHITECTURE.md (ראו סעיף 7).

### 4.2 App Shell (`layout.tsx` + `AppShell`)
- `<html lang="he" dir="rtl">`; גופן Heebo דרך `next/font/google` עם subsets `hebrew` ו-`latin`, משקלים 400 ו-700, כמשתנה CSS.
- `metadata`: כותרת דף "חכמולוגים". `viewport` מוגדר ל-`width=device-width, initial-scale=1`.
- מבנה: `header` (טקסט "חכמולוגים", ממורכז, H1 32px Bold) ← `main` (תוכן המסך, ממורכז, `max-width: 480px`, padding 16–24px) ← `BottomNav`.
- רקע כללי `Background` עם נגיעות פסטל עדינות (כתמים רכים ב-CSS, אופציונלי ופשוט).
- ל-`main` מוגדר `padding-bottom` בגובה הסרגל + `env(safe-area-inset-bottom)` כדי שהתוכן לא יוסתר מאחורי הסרגל.
- **ללא** אייקון הגדרות.

### 4.3 סרגל ניווט תחתון (`BottomNav`)
- `nav` עם `aria-label="ניווט ראשי"`, `position: fixed` בתחתית, רוחב מלא, רקע לבן, קו עליון `Border`, צל רך.
- שלושה פריטים בלבד, בסדר DOM: בית → טריוויה → אודות (ב-RTL "בית" מימין, כמו בתמונות).
  - בית – אייקון בית, `/`
  - טריוויה – אייקון סימן שאלה, `/trivia`
  - אודות – אייקון i בעיגול, `/about`
- יעד פעיל (לפי `usePathname`): טקסט ואייקון בצבע `Primary Text` (`#D13F3F`), קו עליון בצבע `Primary` מעל הפריט, ו-`aria-current="page"`. לא פעיל: `Secondary Text`.
- כל פריט: אייקון מעל תווית Small (14px), אזור לחיצה בגובה 56px לפחות, Focus גלוי.

### 4.4 מסך בית (`/`)
- שורת משנה: "שאלות מעניינות על כל מה שמסקרן אתכם" (Body, `Secondary Text`, ממורכז) — מיד מתחת לכותרת.
- `HomeIllustration`: SVG זמני (DESIGN 2.6) — סימן שאלה, נורה ופאזל בצבעי הפלטה (`Primary`, `Secondary`, `Accent`, `Brand Blue`), עם `role="img"` ו-`aria-label` בעברית (למשל "איור של סימן שאלה, נורה ופאזל").
- כפתור ראשי "בואו נשחק!" — `Link` ל-`/trivia` בעיצוב Primary Button.
- **אין** שדה נושא במסך הבית.

### 4.5 מסך טריוויה (`/trivia`) – ראשוני
- כרטיס (רקע `Light Blue` בהיר או לבן, פינות 16px, צל רך) ובו:
  - `label` גלויה: "איזה נושא מעניין אתכם?" (H3), מקושרת לשדה דרך `htmlFor`.
  - `input type="text"` עם Placeholder "לדוגמה: דינוזאורים, חלל, חיות", `maxLength={100}` (לפי ARCHITECTURE), יישור לימין, Focus בצבע `Brand Blue` 2px.
  - כפתור ראשי "שאלה חדשה" — מושבת כאשר `draftTopic.trim()` ריק.
- השדה והכפתור עטופים ב-`form`; `onSubmit` עושה `preventDefault` ולא מבצע דבר נוסף ב-Milestone זה (החיבור ל-AI ב-Milestone 2). Enter בתיבה אינו טוען את הדף מחדש.
- ערך השדה נשמר ב-`TriviaSessionContext` (`draftTopic`), כך שמעבר לבית/אודות וחזרה שומר את הטקסט (FR-02; ARCHITECTURE 2.3). רענון הדף מאפס — אין `localStorage`.

### 4.6 מסך אודות (`/about`)
- כרטיס לבן מעוגל עם צל רך.
- כותרת H2 "אודות"; כותרת H3 "מה זה חכמולוגים?"; שורה "משחק שאלות על כל מה שמעניין אתכם!".
- רשימה ממוספרת `ol` עם חמשת השלבים מ-DESIGN 1.4, ופסקת הסיום "את השאלות כותב מחשב חכם, ולפעמים גם הוא טועה. אם משהו נראה לכם מוזר, שאלו מבוגר 🙂".
- הטקסט מועתק **מילה במילה** מ-DESIGN 1.4. ללא רכיבים אינטראקטיביים וללא אזור להורים.

### 4.7 בסיס עיצובי (`globals.css`)
- משתני CSS ב-`:root` לכל הצבעים מ-DESIGN 2.1 (כולל הטבלה המשלימה), לגדלי הטיפוגרפיה (32/24/20/16/14), לפינות (16px, 12px לשדה), לצל (`0 2px 8px rgba(0,0,0,0.08)`) ולמרווחים בבסיס 8px.
- Reset בסיסי, `box-sizing: border-box`, `body` ברקע `Background` וטקסט `Text`, `text-align: start`.
- Primary Button: גובה ≥56px, רוחב מלא בתוך התוכן, מילוי `Primary Strong`, טקסט לבן Bold 20px, פינות 16px, צל רך; מושבת: רקע `Border`, טקסט `Secondary Text`, `cursor: not-allowed`.
- Focus גלוי לכל רכיב אינטראקטיבי (`:focus-visible`, קו `Brand Blue`).
- Mobile-first: ללא Breakpoints מורכבים — התוכן ממורכז ב-480px מקסימום בטאבלט ובמחשב, והסרגל התחתון לרוחב מלא.

## 5. בדיקות אוטומטיות (Vitest + React Testing Library)

מינימליות, כדי ש-`npm test` יעבוד כבר מעכשיו (נדרש לפני כל push לפי CLAUDE.md):
- **BottomNav:** מוצגים בדיוק שלושה קישורים — "בית", "טריוויה", "אודות" — בסדר הזה, עם הכתובות הנכונות; הקישור של הכתובת הנוכחית מסומן `aria-current="page"` (`usePathname` מוחלף ב-Mock של `next/navigation`).
- **מסך טריוויה:** הכפתור "שאלה חדשה" מושבת כשהתיבה ריקה או מכילה רווחים בלבד, ופעיל לאחר הקלדת נושא.

## 6. בדיקה עצמית בזמן הבנייה (לפני סימון 🟡)

1. `npm run typecheck`, `npm run lint`, `npm test`, `npm run build` — כולם עוברים.
2. הרצת `npm run dev` ובדיקה בדפדפן המובנה:
   - שלושת המסכים נטענים; מעבר ביניהם מהסרגל; "בואו נשחק!" מוביל ל-`/trivia`; היעד הפעיל מסומן.
   - כל הטקסטים תואמים לטבלה ב-DESIGN 1.4; הממשק RTL.
   - הקלדת נושא → מעבר לאודות → חזרה: הטקסט נשמר. הכפתור מושבת כשהתיבה ריקה.
   - בדיקת פריסה ברוחב טלפון (375px), טאבלט (768px) ומחשב (רוחב מלא): אין חיתוך, אין גלילה אופקית, הסרגל לא מסתיר תוכן.
3. וידוא שאין מפתחות/סודות בקוד ו-`git status` לא מציג קובצי `.env`.
4. סגירת שרת הפיתוח בסיום.
